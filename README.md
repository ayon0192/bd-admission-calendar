# BD Admission Calendar

![Repository checks](https://github.com/ayon0192/bd-admission-calendar/actions/workflows/ci.yml/badge.svg)

A public admission calendar for HSC 2026 candidates in Bangladesh.

## Project Status

Under development.

The project aims to publish verified university admission information, including application periods, admission test dates, and official notices.

## Data Accuracy

- Official university and admission authority notices are the primary sources.
- Unverified information must not be presented as confirmed.
- Conflicting or incomplete information must be clearly marked as pending verification.
- Every published admission record should include its source.

## Security

- Never commit API keys, access tokens, passwords, private keys, or personal credentials.
- Public repository content must be treated as publicly accessible.
- Report security vulnerabilities privately using GitHub's Private Vulnerability Reporting feature.
- See [SECURITY.md](SECURITY.md).

## Contributions

Contributions are welcome through GitHub Pull Requests. Read [CONTRIBUTING.md](CONTRIBUTING.md) before submitting changes.

Please provide reliable sources for admission-related data changes.
